# TravelChina.com - Frontend Static Website

Official frontend static website for **TravelChina.com** (Inbound Tourism Platform for International Travelers).

- Built with modern Semantic HTML5, Tailwind CSS, Schema.org Microdata & JSON-LD structured data.
- Includes Tours, City Destinations Guides, 1-Day Excursions, Curated Hotels, Interactive Tailor-Made Tour Builder, China Travel Insights, and responsive breadcrumb navigation.
